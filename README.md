# PonceEscalier

Guide interactif pour poncer et rénover deux escaliers quart tournant (30 marches) : ponçage marche par marche animé en 3D, contremarches et rambarde en blanc, vitrification des marches.

## Mise en ligne avec GitHub Pages

1. Créez un dépôt public sur GitHub, par exemple `ponceescalier`.
2. Cliquez sur **Add file → Upload files** et déposez tous les fichiers de ce dossier : `index.html`, `manifest.webmanifest`, `sw.js`, `icon-180.png`, `icon-192.png`, `icon-512.png` et ce `README.md`. Ils doivent être à la racine du dépôt, pas dans un sous-dossier.
3. Validez avec **Commit changes**.
4. Ouvrez **Settings → Pages**, choisissez **Deploy from a branch**, la branche `main` et le dossier `/ (root)`, puis **Save**.
5. Après une à deux minutes, l'adresse s'affiche, de la forme `https://votre-nom.github.io/ponceescalier/`.

## Installer sur iPhone

1. Ouvrez l'adresse dans **Safari**.
2. Touchez **Partager**, puis **Sur l'écran d'accueil**.
3. L'icône PonceEscalier apparaît et l'application s'ouvre en plein écran.

La progression est enregistrée sur le téléphone. Après la première ouverture, l'application fonctionne aussi sans connexion.
